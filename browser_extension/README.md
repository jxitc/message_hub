# Message Hub 浏览器插件 — 划选入库

在网页上**选中一段文字**（或右键一张图片），一键存进自建的 Message Hub。
上传形状与网页版「添加」页、手机端完全一致：`type=NOTE`，站点信息进 `metadata`。
三者的校验在服务端是**同一份实现**（`message_ingest.create_message`），不会各写一套。

## 安装（Chrome / Edge / Brave 等 Chromium 系）

1. 地址栏打开 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选这个目录（`message_hub/browser_extension/`）
4. 打开插件的**选项页**（扩展列表里点「详情」→「扩展程序选项」，或右键图标→选项）：
   - 服务器地址：`https://mh.jxitc.com`
   - API key：见下（**必须单独生成一个**）
   - 点「保存并授权该域名」→ 再点「测试连接」
5. 测通之后，任意网页选中文字 → 右键 → **「把选中文字存入 Message Hub」**

> 首次加载若插件报错，`chrome://extensions` 里这张卡片上会显示具体错误；点「服务工作线程」还能看后台日志。

## ⚠️ 必须用**单独的** API key

网页版 `设置 → API Keys` 里生成一个新的（例如命名 `browser-ext`），**不要复用手机那个**。

原因：现在的 key **没有权限分级**，任何一把都等于整个 hub 的读写权（能读你所有短信和邮件）。
单独一把的好处很实际：

- **随时能单独吊销**，不牵连手机；
- 万一某天发现异常，你知道是哪个客户端泄漏的。

key 存在 `chrome.storage.local`（**不参与浏览器账号同步**），也只在请求你配置的那个域名时发送。

## 现在能做什么

| 操作 | 结果 |
|---|---|
| 选中文字 → 右键「把选中文字存入」 | `content` = 选中的文字；`metadata` 带 `url` / `title` / `via=selection` |
| 右键图片 → 「把这张图片存入」 | 图片作为附件（**超 1MB 会自动用 OffscreenCanvas 压到长边 2048 / JPEG**，仍超则拒绝并提示） |
| 右键页面空白 → 「把本页标题与链接存入」 | 存下标题 + 链接，当作书签用 |
| 点插件图标 | 弹窗里快速记一条文字（⌘/Ctrl+Enter 保存） |

站点信息与内容一起留下，所以以后能回答"这句话是从哪抄的"——这正是 hub 存在的意义。

## 已知限制（都实测过或明确可知）

- **跨域 CDN 的图片可能存不下来**：插件只有 `activeTab` 权限（最小权限），能读当前页同源的图片；
  第三方 CDN 上且未开放 CORS 的图片会报「取图失败」。文字选择不受影响。
- **Firefox 不适用**：这是 Manifest V3 + `chrome.*` API 的写法。要支持 Firefox 需要另做一份（MV2/MV3 差异 + `browser.*`）。
- 没有键盘快捷键（那需要额外的 `scripting` 权限去读选区）。目前是"划线 → 右键 → 存入"两步。
  如果你想要 `Ctrl+Shift+S` 直接存，说一声，我加 `scripting` 权限并说明代价。
- 插件**不做**任何后台扫描、不读页面其它内容，只处理你明确选中/右键的那一点。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单。权限：`contextMenus` `storage` `notifications` `activeTab`；**目标域名运行时按需申请**（`optional_host_permissions`），不笼统要 `<all_urls>` |
| `background.js` | 右键菜单、图片预处理（OffscreenCanvas 压缩）、上传、结果反馈（角标 + 通知） |
| `options.html` / `options.js` | 配置 + 域名授权 + **两步测试连接**（先 `/health` 验连通，再带 key 打鉴权接口，避免假阳性） |
| `popup.html` / `popup.js` | 快速记一条文字 |
| `icon128.png` | 图标 |

## 排障

| 现象 | 原因 / 处理 |
|---|---|
| 提示「API key 无效或缺失」 | 选项页没填 key，或 key 被吊销了；重新生成并保存 |
| 提示「连不上服务器」 | 域名没授权（回选项页点「保存并授权该域名」）；或服务器地址写错 |
| 提示「类型不支持」 | 该文件类型不在服务端白名单（图片 / PDF / 纯文本）；zip 之类本来就不收 |
| 提示「文件太大」 | 非图片超 1MB 无法压缩，只能换小文件 |
| 上传成功但列表里没有 | 刷新网页版列表；附件是异步提取的，图片文字稍后才出现 |
